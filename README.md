# Building a Custom Correlation Rule in Wazuh for Brute-Force Detection

## Project Overview

This project demonstrates the design and implementation of a custom correlation rule in Wazuh SIEM for detecting SSH brute-force attacks.

## Objectives

- Deploy Wazuh SIEM
- Configure SSH monitoring
- Simulate brute-force attacks using Hydra
- Develop a custom correlation rule
- Generate and analyze security alerts

## Tools Used

- Wazuh 4.14
- Ubuntu Server 22.04
- Kali Linux
- Hydra
- OpenSSH
- VMware Workstation Pro

## Repository Structure

configs/ - Wazuh configuration files

scripts/ - Attack simulation commands

evidence/ - Screenshots and collected evidence

docs/ - Architecture diagrams

logs/ - Captured logs

report/ - Final report and presentation
